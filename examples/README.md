# Przykłady

- `forms/` — przykładowe definicje formularzy.
- `imports/` — przykładowe paczki i dane importowe.
- `templates/documents/` — przykładowe szablony dokumentów.
- `templates/mail/` — przykładowe szablony wiadomości.
- `templates/footers/` — przykładowe stopki.

Pliki w tym katalogu nie są źródłem danych produkcyjnych. Produkcyjne formularze
i szablony są przechowywane w skonfigurowanym storage Nextcloud.
